Sistema de Gestão de Ações - Possibilidades

Boa ideia! Dá pra construir algo bem funcional e moderno. Vou te apresentar o que é viável e as opções de caminho.

O que HTML puro consegue fazer

HTML + CSS + JavaScript (sem backend) consegue:

  • ✅ Interface moderna, responsiva, dark/light mode
  • ✅ Dashboard com gráficos e cards de status
  • ✅ Filtros, tabelas, modais de criação de ação
  • ✅ Comentários e controle de status visual

Mas não consegue sozinho:

  • ❌ Login real com senha (seria falso, qualquer um veria o código)
  • ❌ Dados persistentes entre pessoas diferentes
  • ❌ Cada usuário ver só o seu

Minha recomendação para o seu caso

Opção A - HTML + Firebase é o melhor equilíbrio:

  • Firebase dá autenticação real (email/senha), banco de dados em tempo real, e hospedagem gratuita - tudo da Google, sem servidor pra gerenciar
  • O visual fica exatamente como você quer - moderno, dark/light, cores vivas - porque você (eu) controla 100% o HTML/CSS
  • Qualquer pessoa com link acessa, sem instalar nada
  • Você e o gestor têm perfil admin, os outros têm perfil usuário

O que o sistema teria

  • Login / Cadastro com email e senha
  • Dashboard pessoal - ações do usuário, status, progresso
  • Aba de metas da equipe - visível para todos, atualizada em tempo real
  • Criação de ações - pelo próprio usuário ou pelo admin
  • Controle de status - Ex: Pendente → Em andamento → Concluído

Firebase - Plano Gratuito (Spark)

O Firebase tem um plano gratuito chamado Spark que é permanente, não expira e não pede cartão de crédito.

Para o tamanho do seu projeto ele é mais do que suficiente:

RecursoLimite gratuitoSeu uso estimado
Usuários (login)Ilimitado~10-20 pessoas
Banco de dados (Firestore)1 GB armazenadoAlguns MB
Leituras/dia50.000Tranquilo
Escritas/dia20.000Tranquilo
Hospedagem10 GB / mêsTranquilo

Nunca vai cobrar nada a menos que você clique conscientemente em "Upgrade to Blaze" - o que não tem nenhum motivo para fazer no seu caso.

O único risco

Se um dia o sistema crescer muito - centenas de usuários fazendo milhares de ações por dia - aí sim chegaria no limite. Mas para uma equipe HSE R&D isso está muito distante da realidade.
